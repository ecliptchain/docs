## **Getting Started with Eclipt 🚀**

To start using **Eclipt**, follow these steps:

1. **Download the Wallet**  
   - Get the latest wallet release from:  
     👉 [Eclipt Wallet Releases](https://github.com/ecliptchain/eclipt-core/releases/tag/v1.0.0)  
   - Alternatively, you can **build it from source** using the instructions in this repository:  
     👉 [Eclipt Source Code](https://github.com/ecliptchain/eclipt-source)  

2. **Syncing with the Network**  
   - Wait for your wallet to **connect to a node**.  
   - If it doesn’t connect, update your `eclipt.conf` file in the wallet directory and restart the wallet.  

💡 Need help? Join our community and get support!
